  kubectl -n {{ .Release.Namespace }} wait --for=condition=complete --timeout=3h job/{{ $job }}

The mcp-server pods wait in Init until the data is in place, then serve /mcp and /healthz:
  kubectl -n {{ .Release.Namespace }} rollout status deploy/{{ $mcp }} --timeout=3h
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ $mcp }} 8000:{{ .Values.mcpServer.service.port }}
  MCP_SERVER_URL=http://127.0.0.1:8000/mcp MCP_AUTH_TOKEN=<token> python -m ccai_mcp.http_smoke
